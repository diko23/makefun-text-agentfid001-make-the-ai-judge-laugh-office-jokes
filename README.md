## Overview

This program emits a single-line office-life joke (under 200 characters) about workplace expectations, taking on extra workload, and manager feedback, written as UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`).

## Run it

The grader runs the entrypoint directly with Node 22:

```sh
node main.ts
```

To test locally with a custom output directory:

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
